# SIG-CLIMA UERN • Sistema de Gestão de Climatização e Refrigeração

Sistema integrado ao **Portal PROAD - UERN** para controle patrimonial térmico, abertura e acompanhamento de chamados, gestão de manutenções preventivas/corretivas, controle de garantias e validação de serviços terceirizados.

## 👥 Perfis de Acesso
- **ADMIN (PROAD / Infraestrutura)**: Gestão global, aprovação de orçamentos, auditoria, homologação de chamados e relatórios consolidados.
- **DEMANDANTE (Unidades / Departamentos)**: Visualização de todos os chamados da unidade, abertura de chamados com cadastro ou seleção de equipamentos, ateste de execução e avaliação de qualidade.
- **EMPRESA (Fornecedor Contratado)**: Diagnóstico técnico, retificação de dados da máquina, envio de orçamentos, comprovação de execução (laudo/fotos) e definição de garantia.

## ❄️ Tipos de Equipamentos Cobertos
1. **Ar-Condicionado (AC)**: Split Hi-Wall, Cassete, Piso Teto, Janela, Portátil (Marca, Tombo, BTUs, Localização).
2. **Refrigerador / Freezer**: Refrigerador 1/2 portas, Freezer Vertical/Horizontal (Marca, Modelo, Litragem, Tombo, Localização).
3. **Bebedouro Industrial**: Inox, Pressão, Central (Marca, Quantidade de Torneiras, Tombo, Capacidade, Localização).
4. **Gelágua / Purificador**: Coluna ou Bancada (Marca, Modelo, Tombo, Tipo de Refrigeração, Localização).

Consulte o arquivo `ARQUITETURA.md` e a pasta `prisma/` para detalhes técnicos de implementação e banco de dados.
